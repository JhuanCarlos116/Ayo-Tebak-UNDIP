Taruh foto-foto ber-geotag (GPS EXIF) di folder ini.

Aturan nama file:  tingkat_Nama Lokasi.jpg
Contoh:
    mudah_Masjid Kampus.jpg
    menengah_Fakultas Teknik.jpg
    sulit_Gang Banjarsari.jpg

Tingkat yang dikenali: mudah | menengah | sulit
(Tanpa awalan tingkat, otomatis masuk "menengah".)

Lalu jalankan di terminal:  npm run build
